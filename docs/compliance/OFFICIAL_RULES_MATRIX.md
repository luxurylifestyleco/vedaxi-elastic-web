The official rules and current Hackathon Website prevail over this matrix if either changes.

## Direct answer: must the project use only OpenAI tooling?

**No OpenAI-exclusive tooling clause was found.** The mandatory technical requirement is a **WebMCP-powered web app**. The official rules expressly allow third-party SDKs, APIs, and data when the entrant is authorized to use them under the applicable terms and licenses. They also allow any hosting provider and permit compliant open-source components and contracted technical assistance subject to ownership conditions.

OpenAI sponsorship, eligibility being limited to jurisdictions supported for OpenAI API services, and optional OpenAI resources do **not** create a rule that every model, API, library, development tool, or hosting service must be supplied by OpenAI. This is a rules interpretation, not permission to use a particular third-party asset: every dependency still needs its own authorization and license review.

## Release-blocking checklist

- [ ] Human eligibility and team representation verified against the complete current rules.
- [ ] WebMCP is genuinely load-bearing and proven in an approved target browser.
- [ ] Live URL remains free and accessible through the end of judging.
- [ ] Public repository contains all tracked source/assets/instructions and a human-selected open-source license.
- [ ] Existing-versus-new work answer is supported by dated evidence.
- [ ] Third-party code, APIs, data, marks, media, audio, and assistance have recorded rights bases.
- [ ] Separate public YouTube demo is `<180s`, has audio, and accurately shows the working project and WebMCP use.
- [ ] Description, tested-client list, and AI-tool disclosure contain only verified current claims.
- [ ] Current official rules and submission fields are re-fetched immediately before the Human Gate.
- [ ] User explicitly acknowledges the rules, then separately authorizes submission.
